# سایت سرمشق (MVP)

سایت ایستا (بدون build و بدون وابستگی) برای آمادگی مصاحبه دانشگاه فرهنگیان.

## اجرا و انتشار
- **محلی:** پوشه را با هر وب‌سرور ساده باز کنید، مثلاً `python3 -m http.server` و سپس `http://localhost:8000`
- **Vercel:** پوشه را در یک ریپو بگذارید و Import کنید (Framework: Other، بدون Build Command، Output Directory خالی). هر commit خودکار منتشر می‌شود.

## افزودن یا ویرایش مطالب (چند ثانیه)
فقط فایل `content/content.js` را ویرایش کنید. قالب:

```
# 🧑‍🎓 عنوان گروه | شناسه        ← مسیر اصلی (تب)
> توضیح کوتاه
## عنوان دسته                  ← بخش داخل گروه
> توضیح اختیاری
### متن سؤال؟                 ← سؤال
پاسخ... (خط خالی = پاراگراف جدید)
💡 نکته                         ← کادر نکته
- مورد فهرست
[جای خالی]                       ← با رنگ مشخص می‌شود
```

- سؤال جدید = یک خط `###` + پاسخ. دسته جدید = یک خط `##`. گروه جدید (مثلاً «پزشکی») = یک خط `#` با شناسه‌ی انگلیسی.
- پیشرفت و نشان‌های کاربران بر اساس **متن سؤال** ذخیره می‌شود؛ ویرایش پاسخ‌ها چیزی را خراب نمی‌کند (تغییر خود متن سؤال، تیک آن سؤال را صفر می‌کند).
- در متن پاسخ از بک‌تیک (`) و `${` استفاده نکنید.

## ساختار
```
index.html        پوسته و دیالوگ PDF
assets/styles.css طراحی (رنگ‌ها از لوگو) + استایل چاپ جزوه
assets/app.js     مسیریابی، جستجو، پیشرفت، شبیه‌ساز، ساخت جزوه
content/content.js همه‌ی محتوا
tools/            اسکریپت‌های یک‌بارمصرف وارد کردن محتوا از چت تلگرام و PDF
```

## خروجی PDF
دکمه‌ی «جزوه PDF» → انتخاب بخش‌ها → پنجره‌ی چاپ مرورگر → *Save as PDF*. جزوه شامل جلد، فهرست، و همه‌ی سؤال‌هاست (حالت «بدون پاسخ» برگه‌ی خودآزمایی می‌سازد).

## داده‌ی کاربر
تیک‌ها، نشان‌ها و نتیجه‌ی آزمون‌ها فقط در `localStorage` مرورگر خود کاربر می‌ماند؛ چیزی به سرور ارسال نمی‌شود.
